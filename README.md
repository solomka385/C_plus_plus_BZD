# C_plus_plus_BZD

Учебный проект по безопасности данных (БЗД) с практическими заданиями на C++.

## Содержание

- `БЗД1_1.docx`, `БЗД1_2.docx`, `БЗД1_3.docx` — задания первой лабораторной работы.
- `БЗД2.docx` — материалы второй лабораторной работы.

Документы содержат постановки задач и результаты выполнения. Файлы `.docx` открываются в Microsoft Word или совместимом редакторе.

## Зависимости

`requirements.txt` содержит общий набор Python-зависимостей, использовавшийся при подготовке учебных материалов.
